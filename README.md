# OpenCV

Me practicing and exploring the basics of OpenCV. The pixels are winning, but I'm catching up.

## What's in here
| Notebook | What it does |
|----------|--------------|
| `OpenCV_Basics_images.ipynb` | Read, draw, resize, rotate, flip, warp perspective, pick an ROI. The "hello world" of pixels |
| `Image_processing.ipynb` | Every blur known to mankind, thresholding, Sobel/Laplacian/Canny edges, color masks |
| `Contours.ipynb` | Finds shapes and tells a triangle from a square. Smarter than some people |
| `GUI_Morphological.ipynb` | Morphology with trackbars, so you can slide things around and feel productive |
| `Face_detection.ipynb` | Haar-cascade face detection + template matching. It found my face. Rude |
| `OpenCV_videos.ipynb` | Video capture/writing, template matching on video, MeanShift & CamShift tracking. Things move, I chase them |

The images, videos and `haarcascade_frontalface_default.xml` are the props these notebooks need.

## How to run
1. Clone it.
2. `pip install opencv-python numpy jupyter`
3. Open a notebook and **change the image/video paths**. I used static paths in every single file. Yes, all of them. You're welcome.

If it can't find a file, check the path before you blame me.
